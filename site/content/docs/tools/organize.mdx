title: Organize
description: Work on any folder by hand. Browse it, find files, read and change the tags inside them, rename or move them and delete what you do not need.
---

Organize is for the messy folders that are not part of a library: a downloads folder, a drive of old backups, a camera dump. Point it at a folder and it shows you what is inside, so you can search, read and change the tags inside the files, move, rename and delete things.

It does not add anything to your libraries. Nothing is saved to the database and the folder is not watched. It reads the folder when you ask, and works on the files when you tell it to.

## Choosing a folder

The first time, click **Choose a folder** and pick one. Parallax remembers it. It then scans the folder, which only counts and sizes what is inside, and shows the totals: how many files, how much space, and how many folders. **Rescan** reads the folder again, and **Change folder** picks another.

## Finding your way around

Folders show as cards with a count of images, videos, audio and other files, plus the total size. Click a card to open it. The trail of links at the top takes you back up, and the browser's Back button works too, because the folder you are in is part of the address.

Use the sort menu next to the **Folders** heading to order them by number of files, size or name, and the buttons at the top right to switch between cards and a list. The **Files** section has its own sort menu.

Open a folder to see the files directly inside it, with thumbnails for pictures and videos. Click **Preview** or **Play** to look at a file without leaving the page. Details like length, size on screen and format are read in the background and fill in as they arrive, shown as "details 12 / 40".

## Searching and selecting

The filter works like the one in [Cleanup](/docs/features/cleanup). You can filter on name, extension, type, size, the date a file was added, and for videos and audio, things like duration, resolution, format and bitrate.

Under the filter is a row of common names. Parallax looks at the words and phrases that show up in the file names and offers them as buttons with a count next to them. Click one to filter to those files, and expand it to narrow it down.

<Shot id="tools/organize/name-groups" />

To pick files, tick them, drag a box around them, or use **Select all that are**, which can pick everything shown, or just the videos, images, audio or other files.

## Looking at the tags inside files

Many files carry their own information inside them: a title, a description, an artist, a date. Downloaded videos often have the title, the description and the channel name. Music has the song, the artist and the album. Photos have the camera, the date taken and sometimes the place. Apps like Plex, Jellyfin and PhotoPrism read these, and sometimes show them instead of the file name. Organize lets you see them, so you know what those apps will see, and [change them](#changing-the-tags-inside-files) when they are wrong.

<Shot id="tools/organize/tags" />

**Columns.** Switch to the list view and a **Columns** menu appears next to the view buttons. Tick the tags you want as columns: title, description, artist, album, genre, date, comment or synopsis. No tag column is shown until you pick some, and Parallax remembers your choice in this browser. A long value is cut to one line, so a description full of hashtags does not make the row taller. Rest the pointer on a value to read more of it (up to the first 500 characters; the panel below shows everything), and click a column heading to sort by it. A dash means the file has no value for that tag.

**Filters.** The filter has a **Tag** option for each of title, description, artist, album, genre, comment and date, and a **Missing tag** option that finds files without one. Tags are read in the background, like the other details, so matches can grow while they arrive. Tags are only read when a column, a filter or the panel needs them.

**The Tags panel.** Select one or more files and press **Tags** in the bar at the bottom. A panel opens on the right and follows your selection:

- With one file it shows the whole title and description, how many characters and hashtags the description has, and every tag exactly as stored. A long description is shortened until you press **Show all**. It also lists the streams in the file, such as the video and audio formats.
- With several files it shows each field once. If all the files agree you see the value. If they differ it says **Mixed** and how many different values there are.

The panel stays open while you keep working, closes with the **Esc** key or its close button, and is remembered between visits. Pictures show their photo information (camera, date taken, and so on) and music shows its song information. When a picture stores the same tag in more than one place, the columns and filters use the first one they find, and the panel lists every place.

## Changing the tags inside files

You change tags in the same panel. Every change takes two steps: you **stage** it, then you **review and apply** it. Nothing is written until you press **Apply**, not even for a single file.

<Shot id="tools/organize/tag-edit" />

**Stage a change.** Select one or more files and open the **Tags** panel. Type in a field and click away (or press **Enter**) to stage the new value for every selected file. If the files disagree the field says **Mixed**, and typing sets the same value for all of them. The **×** next to a field clears it, and the arrow undoes a change you staged. A field marked **Edited** has a change waiting.

The button next to a field opens two tools. **Find and replace** works on the text in that field (with an optional pattern match) and tells you how many of the files would change. **Add text** puts text at the start or the end of each file's own value, for example a tag like `#live` on every description. **Add field…** lists the other fields your files can hold, and **Other tag…** adds a tag with any name your files allow. A tag a file already has shows in the list of tags, where you can edit or clear it. On a photo, the **×** next to **Location** removes where it was taken. A location can be removed but not typed in.

**Review and apply.** When something is staged, **Review changes** appears at the bottom of the panel, and the **Tags** button says how many of the selected files have a change waiting. Staged changes belong to the folder you are in and are never saved. If you open another folder, rescan, choose a different folder to organize, or rename, move or delete a file, the changes for it are dropped.

<Shot id="tools/organize/tag-review" />

The review lists every change as before and after, file by file, and says how each file will be written. A file that already has the value you typed is skipped. **Discard all edits** throws away everything you staged. Press **Apply** to write the files. If the connection drops while it is writing, Parallax cannot tell which files were written, so check their tags before trying again.

**There is no undo.** Applying changes the tags in the files for good, and Parallax does not keep a backup of the old ones.

**What stays untouched.** Parallax changes only the tags you changed. The picture or video, the cover art, lyrics, ratings, your other tags and the file's date stay exactly as they were. After writing, it reads the file again to check that the change really took. If it did not, your original file is left alone and the review says what went wrong.

**How each kind of file is written.** The review shows which of these applies to each file:

- **MKV and WebM** files are changed in place and quickly. If the check fails, the old tags are put back.
- **Music** (MP3, FLAC, Ogg, Opus, M4A) and **MP4-style videos** (MP4, M4V, MOV, 3GP) are written to a copy that then replaces the file, so you need free space about the size of the file. The review shows how much. FLAC, Ogg and Opus keep one text for both the comment and the description, so only **Comment** is shown for them.
- **Pictures** (JPEG, PNG, WebP, GIF) are rewritten the same way. Parallax writes a change to every place that apps look for it, so the title or description agrees everywhere.
- **A few older formats** (AVI, FLV, WMV, WMA, WAV, AIFF) can only keep some tags. They are rewritten, and the review warns that other tags may not survive. Some of them do not allow custom tag names.
- **Anything else**, such as MPEG-TS, MPEG, Ogg video and other picture types, is shown as read-only with the reason.

A file that other names are linked to (a hard link) is not rewritten, because that would break the link. While **Redact names** is on, editing is turned off.

## Doing something with them

A bar at the bottom shows what you have selected, with these buttons:

- **Move to subfolder** asks for a name and puts the files in a folder with that name inside the one you are viewing. The folder is made if it does not exist, or reused if it does. If a file with the same name is already there, the new one gets a number like `(1)` rather than replacing it.
- **Move to folder** moves the files into any other folder under the one you chose, which you pick from a small browser.
- **Rename** changes the name of the selected files. For one file you type the new name. For several you can find and replace text in their names, with an optional pattern match for more complex changes, and a live preview of every result before you confirm. A name that is already taken is skipped, and nothing is ever overwritten.
- **Tags** opens the panel with the tags inside the selected files, where you can also change them (see above). It shows how many of the selected files have a change waiting.
- **Delete** removes the files for good.

To rename a folder, use the pencil on its card.

Moving and renaming are safe. They never overwrite anything.

## Deleting

Deleting in Organize is **permanent**. There is no `_originals` folder and no way back.

- For files, Parallax asks you to confirm and tells you how many and how much space. If that empties a folder, it asks whether to delete the empty folder too.
- For a whole folder, you also have to tick **I'm sure** before the confirm button works.
- The folder you chose at the start can never be deleted.

Files you delete count towards your totals on the Home page.

## Hiding names

**Redact names** is a tick box in the bar at the top of the page, next to **Rescan**. When it is on, it replaces every folder and file name with a placeholder, hides the thumbnails and hides the tag values, and tag editing is turned off. It is useful when you want to share a screenshot without showing what is on your disk.

## Advanced

- Tags are read with `ffprobe` for video and audio and with `exiftool` for pictures. They are written with `mkvpropedit` (MKV and WebM, global tags only, so the tags of single tracks are never touched), `mutagen` (music and MP4-style videos, on a hidden copy next to the file, so scans and the watcher ignore it), `exiftool` (pictures) and, for the few older formats, a stream copy by `ffmpeg`.
- A rewrite checks the copy before it replaces your file: the same number of streams, the same duration (within a tenth of a second, or half a percent of a long file), every changed field reading back as typed and no other field changed. It also checks that the original was not replaced by another job in the meantime. Then it puts the original times, permissions, extended attributes and, where allowed, the owner back. A rewrite that is cut short, for example by a restart, can leave a hidden file starting with `.parallax-tags-` next to the original. The next rewrite in that folder removes ones older than six hours.
- A picture field is written to EXIF, XMP and IPTC together. IPTC holds only short values (a title up to 64 bytes, a description up to 2,000), so a longer value clears the IPTC copy instead of cutting it. Dates are stored as `YYYY:MM:DD HH:MM:SS`.
- Custom tag names for pictures look like `XMP-dc:Source` or `IFD0:Make`. Names that belong to the file itself (such as `File:` or `System:`) are refused.
- A value can be up to 30,000 characters, and text with control characters (other than line breaks and tabs) is refused. Rewrites run one after another, so the space shown is for the biggest single file.
