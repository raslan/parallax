Parallax is a self-hosted app for looking after a big media collection. It runs in Docker on your own machine and you use it from a web browser.

With it you can:

- Browse your videos, images and audio in one place.
- Make videos and audio files smaller without a quality drop you would notice.
- Find duplicates and clear out files you no longer want.
- Rename messy files so Plex, Jellyfin and Kodi recognise them.
- Find and download subtitles for your videos.

New here? Start with [Install](/docs/getting-started/install), then [Your first scan](/docs/getting-started/first-scan). If something goes wrong, [Troubleshooting](/docs/getting-started/troubleshooting) covers the common problems.

The **Advanced** section is for the technical side, like using a graphics card to speed things up. You never need it to get started.
